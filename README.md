### 🏛️ Lindy Stratagem Simulator

**Lindy Stratagem Simulator** — это интерактивный ИИ-тренажер переговорных навыков и стратегического мышления. В отличие от классических EdTech-скриптов, проект построен на синергии современных LLM (Large Language Models) и **Эффекте Линди** — концепции Нассима Талеба о технологиях и идеях, проверенных временем. 

В качестве методологического ядра симулятора используется древневосточная мудрость — **36 китайских стратагем** (на основе [Атласа стратагем](https://pwrmind.github.io/AtlasOfStratagems/)). Симулятор учит топ-менеджеров, переговорщиков и предпринимателей распознавать скрытые манипуляции в бизнесе и выстраивать устойчивые контр-стратегии. 

### 🎯 Ключевые особенности (УТП)

* **Эффект Линди в действии:** Классические методики переговоров (SPIN, Гарвардский метод) появились в XX веке и могут устареть. Стратагемы живут тысячелетиями. Если прием работал во времена Сунь-цзы и работает в современном совете директоров — он будет работать всегда.
* **Архитектура двух ИИ-агентов (Multi-Agent):** 

  * *ИИ-Оппонент:* Ведет жесткие переговоры, скрытно преследуя умысел одной из стратагем.
  * *ИИ-Судья (Методолог):* Невидимо анализирует лог диалога и формирует объективный разбор ошибок и успехов игрока.
* **Полная локальность (Privacy First):** Благодаря интеграции с **Ollama** и моделью **Gemma 2**, симулятор работает на 100% локально. Коммерческие тайны компании и данные переговоров не утекают в сеть.
* **No-Code кастомизация кейсов:** Все сценарии и инструкции для агентов вынесены в изолированные Markdown-файлы. Создание нового бизнес-кейса занимает 2 минуты.

### 🏗️ Архитектура и стек

* **Language:** Python 3.10+
* **Environment & Package Manager:** [uv](https://github.com/astral-sh/uv) (супербыстрый менеджер пакетов от Astral)
* **LLM Engine:** [Ollama](https://ollama.com/) (локальный запуск моделей)
* **Core Model:** gemma2 (или любая другая LLM по выбору, например llama3)

### 🚀 Быстрый запуск

### 1. Подготовка ИИ-модели (Ollama)

Убедитесь, что у вас установлен и запущен Ollama. Загрузите базовую модель: 

bash

ollama run gemma2

Use code with caution.

### 2. Клонирование и настройка окружения

Используйте uv для мгновенной сборки виртуального окружения и установки зависимостей: 

bash

# Клонируйте репозиторий
git clone https://github.com/YOUR_USERNAME/lindy-stratagem-simulator.git
cd lindy-stratagem-simulator

# Инициализируйте окружение и установите зависимости через uv
uv venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
uv add ollama

Use code with caution.

### 3. Структура проекта

Перед запуском убедитесь, что структура файлов выглядит следующим образом: 

text

├── prompts/
│   ├── opponent_case_05.md   # Промпт оппонента (Стратагема №5)
│   └── judge_analyst.md      # Инструкция для ИИ-судьи
├── simulator.py              # Основной исполняемый скрипт
├── pyproject.toml            # Конфигурация проекта (uv)
└── README.md                 # Этот файл

Use code with caution.

### 4. Запуск симуляции

Выполните команду для старта интерактивной сессии в консоли: 

bash

python simulator.py

Use code with caution.

### 🕹️ Механика симуляции (Текущий кейс)

* **Контекст:** Вы продаете партию оборудования. Ваша компания находится в состоянии скрытого кризиса (кассовый разрыв, срочно нужен кэш).
* **Скрытая атака ИИ:** Оппонент (директор по закупкам ритейлера) тайно использует **Стратагему №5 «Взять в долг огонь, чтобы совершить поджог»** (использование уязвимостей и внутренних проблем противника ради своей выгоды).
* **Ваша задача:** Провести раунды переговоров, не поддаться на жесткий прессинг, сохранить маржинальность или вовремя вскрыть манипуляцию, перехватив инициативу.

### 📈 Перспективы масштабирования (Roadmap)

1. **Интерфейс «Вскрытия карт»:** Добавление UI-команд (например, /guess [номер]), позволяющих игроку прямо во время диалога заявить: *"Я вижу твою стратагему!"* с автоматическим начислением игровых очков мудрости.
2. **Интерактивный Атлас:** Интеграция с веб-картой [Atlas of Stratagems](https://pwrmind.github.io/AtlasOfStratagems/) для динамической подсказки контр-стратагем в реальном времени.
3. **Голосовой режим:** Подключение локальных моделей Whisper (STT) и Silero (TTS) для имитации реального телефонного звонка или Zoom-встречи.
